# Sports Terminal Management System
A C# console application built on .NET 10 designed to manage sports terminal administrative workflows, scheduling, and operational tasks through a lightweight command-line interface.

## Features
- **Terminal-Based Control:** Streamlined console interface for terminal administrators and operators.
- **Record & Schedule Management:** Manage sports terminal queues, session allocations, and administrative records.
- **Modern .NET Architecture:** Built with C# and targeting .NET 10 for fast execution and minimal runtime overhead.

## Tech Stack
- **Language:** C#
- **Platform:** .NET 10.0
- **Application Type:** Console Application
- **IDE:** Visual Studio / VS Code
